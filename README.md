# For GitHub — Telegram Mini App

Личное приложение для слов, привычек, важных дат и фокуса. Доступ к данным есть только у владельца бота: сервер проверяет подпись Telegram и `OWNER_TELEGRAM_ID`.

- **Словарь:** английский и китайский, интервальные повторения SM-2, списки, CSV-импорт, озвучка, Wiktionary и Tatoeba. Китайский пиньинь берётся из CC-CEDICT.
- **Привычки:** ежедневные отметки, история, серии и архив.
- **Отсчёты:** дни до важной даты или после неё.
- **Фокус:** темы, обратный отсчёт и секундомер, сохранение активной сессии в браузере.
- **Бот:** `/start`, `/stats`, утренний дайджест, вечернее напоминание и ежедневная резервная копия.

Интерфейс адаптирован для телефона и компьютера. Выбран стиль «Хороший темп»: графитовый фон, светлый акцент и собственные иконки. Штатная кнопка «Назад» Telegram закрывает форму или возвращает в родительский раздел; в обычном браузере её заменяет кнопка в шапке. Сервер — FastAPI и aiogram, данные — SQLite, интерфейс — React и Vite. Docker собирает интерфейс и отдаёт его из того же приложения.

Проект разработан с помощью ИИ. Требования, выбор дизайна и проверка поведения приложения — автор проекта.

## Запуск

Нужен запущенный Docker Desktop.

```sh
cp .env.example .env
```

Заполни в `.env`:

| Переменная | Значение |
| --- | --- |
| `BOT_TOKEN` | Токен от [@BotFather](https://t.me/BotFather) |
| `OWNER_TELEGRAM_ID` | Твой числовой Telegram ID |
| `WEBAPP_URL` | Можно оставить пустым для временного Cloudflare-туннеля |
| `TZ` | Часовой пояс, по умолчанию `Europe/Moscow` |
| `DIGEST_HOUR` | Час утренней сводки, по умолчанию `8` |
| `REMIND_HOUR` | Час вечернего напоминания, по умолчанию `20` |
| `TUNNEL_ARGS` | Можно оставить пустым; для своего туннеля — `run --token …` |

```sh
docker compose up -d --build
```

Затем отправь боту `/start`. На macOS также можно открыть `panel.command` двойным кликом или выполнить `./start.sh`. После изменения кода пересобери приложение командой выше.

По умолчанию Cloudflare выдаёт временный HTTPS-адрес. Бот обновляет кнопку меню при смене адреса. Кнопки в старых сообщениях остаются прежними: используй меню бота или отправь `/start` ещё раз. Для постоянного адреса задай `WEBAPP_URL` и параметры своего туннеля.

Локальный порт приложения — `127.0.0.1:8010`; наружу приложение открывается через туннель. `TZ` передаётся в контейнер, чтобы напоминания и календарная статистика использовали выбранный часовой пояс.

## Разработка

Python 3.12+ и Node.js 22.

Из корня проекта:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements-dev.txt
```

API в отдельном терминале:

```sh
cd backend
DEV_MODE=1 BOT_TOKEN='' DB_PATH=./app.db TZ=Europe/Moscow ../.venv/bin/python -m uvicorn main:app --reload --host 127.0.0.1
```

Интерфейс во втором терминале:

```sh
cd web
npm ci
npm run dev -- --host 127.0.0.1
```

Открой адрес, который напечатает Vite. Он передаёт `/api` на `127.0.0.1:8000`. В Docker интерфейс собирается автоматически; локальная разработка использует Vite.

`DEV_MODE=1` отключает проверку Telegram и предназначен только для локальной разработки. Не передавай его в публично доступный сервер. Команды выше используют отдельную локальную базу и не запускают бота.

Словарь загружается страницами по 80 слов, поиск отправляется после короткой паузы ввода. Повторные запросы одного ресурса объединяются. При отметках привычек меняются только связанные данные; активная колода повторений сохраняется до конца тренировки.

Активный фокус-таймер сохраняется в браузере, в localStorage; завершённые сессии — в SQLite. Повторная отправка результата сессии использует тот же идентификатор и не создаёт вторую запись. Обновление базы добавляет служебные столбцы, сохраняя существующие записи.

Проверки из корня:

```sh
.venv/bin/python backend/test_logic.py
python3 -m unittest discover -s scripts -p 'test_*.py'
python3 scripts/check_publication.py
npm --prefix web test
npm --prefix web run build
```

## Данные и резервные копии

Слова и переводы, история повторений, привычки, отметки, отсчёты и завершённые фокус-сессии хранятся в одной SQLite-базе. Отчёты рассчитываются из её записей.

Docker Compose подключает именованный volume `data` к `/data`. Полное имя volume зависит от имени Compose-проекта. Данные хранятся локально под управлением Docker, отдельно от исходников.

SQLite хранится в Docker volume по пути `/data/app.db`. В 03:00 бот сохраняет копию в `/data/backups/`. Обычный `docker compose down` сохраняет volume; `docker compose down -v` удаляет его вместе с данными.

Забрать резервные копии:

```sh
docker compose cp app:/data/backups ./backups
```

Создать копию вручную:

```sh
docker compose exec app python -c "import bot; bot.backup()"
```

Перед восстановлением останови приложение и сохрани текущую базу. Восстанавливай SQLite через backup API, чтобы не смешивать новую базу со старыми WAL-файлами. Папки с данными и копиями не публикуются в Git.

Словарь принимает CSV с заголовком `text,translation,language,transcription,example,list`. Обязательны `text` и `translation`; язык — `en` или `zh`. Данные словаря, привычек и фокуса можно выгрузить через `/api/export/words.csv`, `/api/export/habits.csv` и `/api/export/focus.csv` с Telegram-заголовком `X-Init-Data`.

При запуске без Docker путь к базе задаётся через `DB_PATH`. Команда разработки выше создаёт `backend/app.db`. Локальный `.env`, базы, резервные копии и экспорты исключены через `.gitignore`. Секреты также исключены из контекста сборки Docker.

## Источники словаря

Для автозаполнения не нужны отдельные API-ключи. Английская транскрипция и русские переводы запрашиваются у Wiktionary через публичный HTTP API. Примеры предложений с русским переводом загружаются из Tatoeba. Эти функции требуют интернета. При запросе соответствующему сервису передаётся искомое слово.

Для китайского используется [CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cedict): при первом обращении файл скачивается рядом с базой (`/data/cedict.txt.gz` в Docker), затем читается локально. Он содержит пиньинь и английские значения; русские переводы китайских слов нужно вводить самостоятельно. Файл не входит в Git. CC-CEDICT распространяется под CC BY-SA 4.0; при распространении словарных данных нужно соблюдать эту лицензию.

Ответы API и CSV-экспорты помечаются `Cache-Control: private, no-store`. Контейнер запускается без HTTP access log, чтобы поисковые запросы не оставались в журнале запросов. Доступ к API по-прежнему требует подписанный Telegram initData владельца.
